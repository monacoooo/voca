토익을 처음 준비하는 대학생과 취업 준비생을 위한 앱

토익 기출 어휘 1,396개를 Day 단위(기본 하루 10개)로 나눠 학습합니다. 설치 없이 웹 브라우저에서 바로 쓰고, 학습 기록은 사용자 기기에 저장됩니다.

사용 상황

통학·공강 사이 휴대폰으로 짧게

수준

토익 초보~중급, 시험 구성을 아직 모르는 사람 포함

필요

매일 열어볼 동기와 영어 문장 속 사용 연습

하루 5~10분은 팀의 가정이며, 실제 학습 시간은 아직 사용자 인터뷰로 확인하지 않았습니다.

외우고, 듣고, 문장으로 써 보며 익힙니다

  • Day별 학습하루 10개씩 Day로 나눠, 단어 소개 후 객관식·빈칸·듣기·문장 만들기 문제
  • 문장 만들기틀린 단어를 손가락으로 잡아 옮겨 다시 배치
  • 복습오답노트, 5단계 복습, 단어장(카드 스와이프 또는 표)으로 언제든 다시 보기
  • 발음카드를 뒤집으면 발음이 자동으로 재생

배운 만큼 비행하고, 도착하면 비자 도장을 받습니다

10km하루 학습마다
30km비자 도장 1개 (약 3일)
8곳목적지별 영문 도장

상점에서 비행기 8종과 여권 커버 6종을 보석으로 구매하고 장착합니다. 여권 목적지는 게임 설정이며 실제 비자와 무관합니다.

매일 열어볼 이유와, 처음인 사람을 위한 안내

  • 출석 습관접속하면 출석 도장이 찍히고, 연속 출석이면 안내 팝업이 뜹니다. 레벨을 누르면 출석 캘린더가 열립니다.
  • 첫 토익 안내시험 구성과 용어 풀이, 공식 사이트·유튜브 링크를 한 탭에 모았습니다. 시험 구성 숫자는 한국 TOEIC위원회 공식 사이트를 확인해 넣었습니다.
